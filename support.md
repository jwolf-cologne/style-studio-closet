# Style Studio Support

Need help with Style Studio?

## Contact

Email: style-studio-support@jenswolf.dev

Please include:

- your device model
- your iOS version
- a short description of the issue
- screenshots, if helpful

## Common Topics

### In-App Purchases

Subscriptions and purchases are handled by Apple. If a purchase does not appear immediately, use the restore purchases option in the app.

### AI Features

AI features require an internet connection and may be unavailable if the backend service cannot be reached.

### Photos

If camera or photo access is not working, check iOS Settings > Privacy & Security > Camera or Photos and make sure Style Studio has permission.
